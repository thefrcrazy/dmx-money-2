# Icônes du GNOME Icon Development Kit

Icônes symboliques embarquées par l'app Linux quand le thème Adwaita n'a pas d'équivalent.
Elles viennent du [GNOME Icon Development Kit](https://gitlab.gnome.org/Teams/Design/icon-development-kit)
et sont distribuées sous licence [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

`scripts/gen-native-icons.py --fetch` télécharge celles que `shared/icons/native.json` référence
(`kit:<nom>`) et les copie dans l'app Linux.
